# Calculadora Modular em Python

Projeto desenvolvido para praticar conceitos de Git, GitHub Flow e trabalho colaborativo em equipe.

A aplicação consiste em uma calculadora modular em Python, onde cada funcionalidade foi separada em módulos independentes para facilitar a organização do código e o versionamento.

O objetivo principal do projeto foi treinar:

- Criação de branches (`feature/*`)
- Commits semânticos
- Pull Requests
- Merge entre branches
- Organização de código em módulos
- Testes automatizados com `pytest`

---

# Funcionalidades

## Módulo Básico

- Soma
- Subtração
- Multiplicação
- Divisão

## Módulo Potência

- Potência
- Raiz quadrada
- Raiz cúbica

## Módulo Percentual

- Cálculo percentual
- Acréscimo
- Desconto

## Módulo Estatística

- Média
- Mediana
- Desvio padrão

## Módulo Conversão

- Celsius para Fahrenheit
- KM para Milhas
- KG para Libras

# Como Executar o Projeto

Clone o repositório:

```bash
git clone <url-do-repositorio>
```

Entre na pasta do projeto:

```bash
cd calculadora-gcs
```

Execute o projeto:

```bash
python main.py
```

---

# Como Executar os Testes

Instale o pytest:

```bash
pip install pytest
```

Execute os testes:

```bash
pytest
```
